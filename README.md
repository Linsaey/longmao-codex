# 龙猫放置 · 图鉴（单页版）

游戏《龙猫放置》的离线图鉴。一个 HTML 页面 + 一份数据文件 + 一批压缩图标，纯前端无依赖，
手机浏览器和电脑浏览器都能直接打开。

## 内容

| 分类 | 数量 | 说明 |
| --- | --- | --- |
| 怪物 | 161 | 等级、HP/MP、攻击区间、防御、暴击/闪避/命中、攻速、经验、出现地图、掉落 |
| 装备 | 627 | 槽位、需求等级、职业限制、属性、特殊效果、套装归属、掉落来源 |
| 道具 | 519 | 消耗品 / 材料 / 拼图 / 拼图块 / 特殊 / 券，含说明、效果与来源 |
| 技能 | 143 | 职业、武器限制、逐级数据（需求等级 / 倍率 / 冷却 / 耗蓝） |
| 套装 | 23 | 档位效果 + 套装成员 |
| 地图 | 47 | 区服、等级段、每波只数、怪物清单 |
| 药水 BUFF | 68 | 加成属性、加成值、持续时间 |

支持按名称/ID 搜索，分类内带筛选（区服、槽位、道具类型、职业）。

## 掉落概率口径

数据来自游戏本体静态表 `/data/drops.json`，概率按客户端 `Nv()` 的结算逻辑复算：

- `rollMode = independent`：逐条独立判定，概率即 `chance`。
- `rollMode = group_pick_1`：按 `pool` 分组，**整池概率 = 池内首行的 `chance`**，
  命中后池内等概率随机取一条 → **单件真实概率 = 池概率 / 池内件数**。

因此怪物详情里同一装备池内的每件装备概率相同（如 10% / 23 件 ≈ 0.435%）。
单件概率低于 0.05% 的池不在明细里逐条列出，只在「其它池」里给出整池概率与件数。

## 目录

```
index.html        页面（结构 + 样式）
app.js            渲染逻辑（分类、搜索、筛选、详情弹层）
data.js           打包后的游戏数据（window.CODEX = {...}）
img/              910 张压缩图标（怪物 96px JPEG，物品/技能 56px WEBP）
build_codex.py    从游戏静态表重新生成 data.js 与 img/ 的构建脚本
```

## 本地打开

直接用浏览器打开 `index.html` 即可（`data.js` 与 `img/` 需在同一目录）。

## 重新生成数据

```bash
python build_codex.py
```

脚本会从 `C:\Temp\g4data\*.json`（游戏静态表本地副本）与 `C:\Temp\imgcache`
（图标原始缓存）读取，重新压缩图标并输出 `data.js`。原始表可用
`http://43.142.100.84:8080/data/<表名>.json` 重新抓取。
